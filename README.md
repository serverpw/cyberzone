# cyberzone

Repositori ini berisi halaman statis untuk SIMULASI pelatihan kesadaran keamanan (phishing awareness). Halaman menampilkan contoh pesan yang terlihat mencurigakan dan menuntun peserta untuk mengidentifikasi tanda-tandanya.

Penting: repositori ini dibuat untuk tujuan edukasi dan latihan internal. Jangan digunakan untuk menipu atau menyerang pihak lain.

Contents:
- index.html — halaman utama simulasi (Bahasa Indonesia)
- styles.css — styling dan desain kartun/maskot (Kiko)
- LICENSE — MIT (dibuat saat repositori dibuat)

Deploy ke GitHub Pages
1. File sudah ada di branch `main`.
2. Aktifkan GitHub Pages di Settings -> Pages -> pilih branch `main` dan folder `/ (root)`.
3. Tunggu beberapa menit, lalu akses: `https://<your-username>.github.io/cyberzone` (atau `https://serverpw.github.io/cyberzone` jika akun serverpw adalah pemilik).

Catatan administratif
- Pastikan peserta mendapatkan pemberitahuan bahwa ini hanyalah simulasi.
- Jangan menyertakan data nyata peserta pada latihan.

Jika Anda mau, saya bisa:
- Tambahkan gambar/maskot yang lebih detail,
- Tambah form pelaporan otomatis ke email internal atau webhook,
- Buatkan branch `private-templates` untuk variasi latihan,
- Otomasi aktivasi GitHub Pages (butuh permission/akses tambahan).
